# Daily HQ

Personal daily planning dashboard — schedule, tasks, workouts, and meal plan in one view.

## Setup (GitHub Pages)

1. Create a new GitHub repo (e.g. `daily-hq`)
2. Push all files in this folder to `main`
3. Go to **Settings → Pages → Source: main branch / root**
4. Visit `https://yourusername.github.io/daily-hq`

## How to customize

All your personal data lives in **`config.js`** — open it and edit:

| Section | What to change |
|---|---|
| `blocks` | Add/remove/edit recurring time blocks |
| `workouts` | Swap exercises, change days |
| `meals` | Update dinners for any day |
| `eatOutDay` | Change your eat-out day (0=Sun … 6=Sat) |

## Adding daily tasks

Tasks are saved in your **browser's local storage** — no login needed.
- Type in the box at the bottom of the Tasks card and press Enter or Add
- Check them off as you go
- They auto-clear the next day (each day gets a fresh list)
